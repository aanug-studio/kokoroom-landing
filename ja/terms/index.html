利用規約

第1条（目的）

本規約は、KokoRoomの利用に関してaanug（以下「当社」）と利用者の権利、義務および責任を定めます。

第2条（定義）

  1. 「利用者」とは、本規約に同意してサービスを利用する人をいいます。
  2. 「サービス」とは、周期の記録・予測、今日の天気、カレンダー、コンディション記録、パートナー接続、ベンチ（気持ちを送る）、通知、フィードバック、アカウントのバックアップ・復元など、当社が提供するKokoRoomおよび関連機能をいいます。
  3. 「アカウント」とは、記録・設定のバックアップと復元のため利用者が任意で連携するアカウントをいいます。連携せずに基本機能を利用することもできます。
  4. 「アカウントバックアップ」とは、案内された記録・設定を当社サーバーに保存し、別の端末や再インストール後に復元する機能です。
  5. 「パートナー」とは、招待コードを通じて接続し、限られた共有情報を受け取る別の利用者をいいます。

第3条（規約の効力・変更）

  1. 当社は関係法令の範囲内で本規約を変更し、その内容をサービス内で告知します。
  2. 利用者に不利益となる変更は、施行日の少なくとも30日前に告知します。

第4条（利用条件・アカウント連携）

  1. サービスは満14歳以上を対象とし、14歳未満の利用は制限されます。
  2. アカウントを連携しなくても基本機能を利用できます。
  3. 記録・設定のバックアップと復元のため、対応するアカウントを任意で連携できます。
  4. バックアップを選択した場合、連携アカウントの識別子とサービスで指定した記録・設定を、当社サーバーでバックアップ・復元のために処理します。
  5. 健康・性生活の記録を含む場合など、バックアップの範囲はアカウント連携前に別途案内します。

第5条（サービスの提供）

当社は周期の記録・予測、今日の天気の案内、カレンダー、コンディション記録、パートナー接続、ベンチ（気持ちを送る）、通知、フィードバック、アカウントのバックアップ・復元などを提供します。

第6条（健康情報・医療に関する免責）

  1. 周期の段階、排卵、PMS、コンディションなどの案内は、一般的な健康管理の参考情報であり、病気の診断・治療や、避妊・妊娠の判断を目的としません。
  2. 健康に関する判断は、資格を持つ医療専門家にご相談ください。

第7条（入力情報の責任）

月経日、症状、性生活、ピルの服用、メモ、パートナーコードなどは利用者が直接入力し、その正確性に責任を負います。当社は不正確な入力に起因する予測・案内の誤りについて責任を負いません。

第8条（パートナー接続）

  1. 招待コードで接続し、接続リクエストの承認・拒否・キャンセルや接続終了を行うことができます。
  2. 接続すると、今日の周期の天気と周期予測が提供されます。実際の月経記録、直近最大6か月の分析、過去・現在のコンディション、気分・身体・生活・セルフケア・利用者追加項目・メモなどは、利用者が共有範囲で明示的に有効にした項目に限り、接続相手に提供できます。未選択の情報は提供せず、接続解除や共有範囲の縮小が確認されると、その範囲外の情報は表示されなくなります。
  3. 相手の周期・コンディション情報を同意なく保存・撮影・共有したり、嫌がらせなどに使用したりしてはなりません。

第9条（通知・ベンチ機能の限界）

  1. ローカル通知・プッシュ通知は、OSの権限、ネットワーク、端末の状態によって遅れたり届かなかったりする場合があります。
  2. ベンチは自由入力のチャットではありません。定型の気持ち、つつく機能、受け取った気持ちの瓶を提供します。利用できる操作や履歴はアプリのバージョン・会員状態によって異なり、制限はアプリ内に表示します。

第10条（利用者の義務・禁止事項）

利用者は次の行為をしてはなりません。

  • 他人のアカウント・招待コードを無断で使用すること
  • 虚偽の情報を入力すること
  • サービスの運営を妨害すること
  • サービスをリバースエンジニアリングすること
  • 当社や第三者の権利を侵害し、または違法・権利侵害の目的でサービスを利用すること

第11条（有料サービス）

  1. 任意で購入できるKokoRoom Plusの月額・年額自動更新サブスクリプションと、非消耗型の買い切り永久利用権を提供します。永久利用権は一度の支払いで、定期的な購読料はありません。Plusを購入しなくても基本機能を利用できます。
  2. 特典、請求期間、価格、通貨、対象のトライアルや期間限定特典は、支払い前にアプリおよびApp Store・Google Playの購入確認画面に表示します。商品・特典はストア、国、利用資格によって異なる場合があります。案内を閲覧するだけで購入する必要はありません。
  3. 月額・年額購読は、購入したストアで解約しない限り同じ期間で自動更新されます。料金はApp Store・Google Playアカウントに請求されます。無料トライアルも期限内に解約しない場合、ストア確認画面に示す日付・価格で有料購読に移行します。Appleの購読は、更新を避けるため現在の期間またはトライアル終了の少なくとも24時間前に解約してください。
  4. Appleの購読はiPhoneの設定 > 自分の名前 > サブスクリプション、Google Playの購読はGoogle Play > お支払いと定期購入 > 定期購入から管理・解約できます。公式のAppleの解約案内またはGoogle Playの解約案内をご覧ください。アプリの削除、KokoRoomアカウントの連携解除・削除、パートナー接続終了ではストア購読は解約されません。
  5. 購入は該当ストアで検証し、購入に使用したKokoRoomアカウントに紐づけます。復元にはそのKokoRoomアカウントと購入元ストアのアカウントを使用し、KokoRoom Plus画面で購入の復元を選んでください。別のKokoRoomアカウントに紐づく購入を、復元だけで付け替えることはできません。
  6. Plus利用権が有効な間、アプリの案内に従い、現在接続中のパートナーも共有特典を利用できます。購入所有権を移転したり、双方の記録共有権限を変更したりするものではありません。
  7. 返金・購入のキャンセルは関係法令と購入元ストアの方針に従います。自動更新の解約と返金申請は異なります。利用権は、有効期限や返金を含むストアで確認した状態に応じて反映されます。
  8. iOSアプリのライセンスにはAppleの標準エンドユーザー使用許諾契約（利用規約 / EULA）が適用されます。本規約はKokoRoomの運営を説明するもので、その契約を置き換えたり、法定の消費者の権利を制限したりしません。

第12条（サービスの変更・停止）

当社はFirebaseなどの外部インフラ、ネットワーク、システム保守、方針変更などにより、サービスの全部または一部を変更・一時停止する場合があります。

第13条（連携解除・データ削除）

  1. 端末で連携を解除しても、バックアップのため当社サーバーに保存済みの記録・設定は削除されません。
  2. サービスのアカウント・データ削除手続きを通じて、連携アカウントとサーバー上のバックアップを削除できます。
  3. 削除依頼があった場合、当社はサーバー上の利用者記録、認証・アカウント連携情報など、削除対象の情報を削除し、または削除のため合理的な措置を講じます。
  4. お問い合わせ・フィードバック、法令上保存が必要な情報、一部のバックアップ・ログは、必要な期間または別途定めた期間保存する場合があります。

第14条（著作権）

サービスおよび当社が制作するすべてのキャラクター・画像・文章・コンテンツの著作権は当社に帰属します。

第15条（免責）

当社は天災、システム障害、利用者に帰責する事由による損害について責任を負いません。ただし、関係法令上責任を免除できない場合を除きます。

第16条（個人情報の保護）

  1. 当社は関係法令に従って個人情報を保護します。詳細はプライバシーポリシーをご覧ください。
  2. バックアップを選択した場合、連携アカウントの識別子と案内した記録・設定をバックアップ・復元のために処理します。
  3. 健康・性生活に関する記録を含む場合など、バックアップの範囲は連携前に別途案内します。
  4. 端末で連携を解除するだけではサーバー上のバックアップは削除されません。サービスのアカウント・データ削除手続きで削除できます。
