服务条款

生效日期：2026年6月11日

最后更新：2026年10月7日 — KokoRoom Plus购买、续订与恢复说明

网站语言新增日期：2026年10月12日。现有服务使用条款不变。

第1条（目的）

本条款规定aanug（以下简称“公司”）与用户之间有关KokoRoom服务使用的权利、义务及责任。

第2条（定义）

  1. “用户”指同意本条款并使用服务的人。
  2. “服务”指公司提供的KokoRoom及其相关功能，包括周期记录与预测、今日天气、日历、状态记录、伴侣连接、长椅（传递心意）、通知、反馈、账号备份与恢复。
  3. “账号”指用户为备份和恢复记录及设置而选择连接的账号。不连接账号也可使用基本功能。
  4. “账号备份”指将服务说明范围内的记录和设置存储在公司服务器，以便在其他设备或重新安装后恢复的功能。
  5. “伴侣”指通过邀请码连接并接收有限共享信息的另一位用户。

第3条（条款的效力与修改）

  1. 公司可在适用法律允许的范围内修改条款，并在服务内公告变更。
  2. 如变更对用户不利，公司将在生效前至少30天予以通知。

第4条（使用条件与账号连接）

  1. 服务面向年满14岁的用户，不满14岁的用户受使用限制。
  2. 用户无需连接账号即可使用基本功能。
  3. 用户可选择连接服务支持的账号，以备份和恢复记录及设置。
  4. 选择账号备份后，关联账号标识和服务指定的记录及设置会在公司服务器上为备份与恢复而处理。
  5. 备份范围，包括可能涉及的健康及性生活记录，会在连接账号前单独说明。

第5条（服务提供）

公司提供周期记录与预测、今日天气提示、日历、状态记录、伴侣连接、长椅（传递心意）、通知、反馈、账号备份与恢复等功能。

第6条（健康信息与医疗免责声明）

  1. 服务提供的周期阶段、排卵、PMS和状态提示仅供一般健康管理参考，不用于诊断、治疗任何疾病，也不用于判断避孕或怀孕。
  2. 涉及健康的决定应咨询合格的医疗专业人员。

第7条（用户输入信息的责任）

月经日期、症状、性生活、避孕药服用记录、备注、伴侣代码等由用户直接输入，用户对其准确性负责。公司不对因输入不准确导致的预测或提示错误承担责任。

第8条（伴侣连接）

  1. 用户可通过邀请码连接伴侣，并接受、拒绝、取消连接请求或终止连接。
  2. 连接后会提供今日周期天气和周期预测。实际月经记录、最近最多6个月的分析结果，以及过去或当前的状态、心情、身体、生活、自我照护、自定义项目和备注等，仅在用户明确开启对应共享项目时提供给当前伴侣。未选择的项目不共享；确认断开连接或缩小共享范围后，不再显示范围外的信息。
  3. 不得未经同意保存、截图或分享伴侣的周期及状态信息，也不得将其用于骚扰或类似目的。

第9条（通知与长椅功能的限制）

  1. 本地通知和推送通知可能受操作系统权限、网络或设备状态影响，出现延迟或无法送达。
  2. 长椅并非自由文字聊天功能，而是提供预设心意、轻戳以及收到心意的玻璃瓶。可用操作和历史记录视应用版本与会员状态而异，适用限制会在应用内显示。

第10条（用户义务与禁止行为）

用户不得：

  • 未经授权使用他人的账号或邀请码
  • 输入虚假信息
  • 干扰服务运营
  • 对服务进行逆向工程
  • 侵犯公司或第三方权利，或将服务用于违法或侵权目的

第11条（付费服务）

  1. KokoRoom提供可选的KokoRoom Plus月度、年度自动续订订阅，以及非消耗型终身购买。终身购买为一次性付款，不产生循环订阅费用。不购买Plus也可使用基本功能。
  2. 可用权益、计费周期、价格、货币以及适用的试用或限时优惠，会在付款前于应用和App Store或Google Play购买确认页面显示。商品及优惠可能因商店、国家和资格而异。仅查看优惠无需购买。
  3. 月度和年度订阅在未通过购买商店取消时，会按相同周期自动续订，费用向用户的App Store或Google Play账号收取。符合条件的免费试用如未及时取消，将按商店确认页面显示的日期和价格转为付费订阅。Apple订阅应至少在当前周期或试用结束前24小时取消，以避免续订。
  4. Apple订阅可在iPhone设置 > 您的姓名 > 订阅中管理或取消；Google Play订阅可在Google Play > 付款和订阅 > 订阅中处理。请参阅官方Apple取消说明或Google Play取消说明。删除应用、断开或删除KokoRoom账号、终止伴侣连接均不会取消商店订阅。
  5. 购买会通过相应商店验证，并关联至购买时使用的KokoRoom账号。恢复符合条件的购买时，请使用该KokoRoom账号及原购买商店账号，在KokoRoom Plus页面选择恢复购买。已经关联其他KokoRoom账号的购买不能仅凭恢复操作转移归属。
  6. Plus权限有效期间，当前连接的伴侣也可按应用说明享受共享权益。这不会转移购买归属，也不会更改双方的记录共享权限。
  7. 退款和购买取消按适用法律及购买商店的政策处理。取消自动续订不同于申请退款。使用权限会反映商店验证的状态，包括到期或退款。
  8. iOS应用许可适用Apple的标准最终用户许可协议（使用条款 / EULA）。本服务条款说明KokoRoom的运营，不取代该许可协议，也不限制法定消费者权利。

第12条（服务变更与暂停）

公司可因Firebase等第三方基础设施、网络状况、系统维护或政策变化等原因，修改或暂时停止全部或部分服务。

第13条（账号断开与数据删除）

  1. 在设备上断开账号不会删除已为账号备份而存储在公司服务器上的记录和设置。
  2. 用户可通过服务的账号及数据删除流程，删除已连接账号和服务器备份。
  3. 收到账号及数据删除请求后，公司会删除或采取合理措施删除应删信息，包括服务器中的用户记录、认证或账号连接信息。
  4. 咨询和反馈记录、依法应保留的信息，以及部分备份或日志，可能在必要或另行规定的期限内继续保留。

第14条（著作权）

服务以及公司创作的所有角色、图像、文字和内容的著作权归公司所有。

第15条（免责）

公司不对自然灾害、系统故障或可归责于用户的原因造成的损失承担责任，但法律不允许免除责任的情况除外。

第16条（个人信息保护）

  1. 公司依法保护用户个人信息，详情见隐私政策。
  2. 选择账号备份后，关联账号标识及已向用户说明的记录和设置会用于备份与恢复。
  3. 包括可能涉及的健康及性生活记录在内，账号备份范围会在连接前单独说明。
  4. 仅在设备上断开账号不会删除服务器备份，用户可通过服务的账号及数据删除流程删除。
